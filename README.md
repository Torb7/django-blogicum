# Блогикум

«Блогикум» — платформа для публикации записей, общения пользователей и чтения тематических блогов. Проект реализован на Django и использует стандартную модель пользователя Django.

## Возможности

- регистрация, вход, выход и восстановление пароля;
- просмотр профиля пользователя с информацией об аккаунте и его публикациях;
- редактирование имени, фамилии, логина и электронной почты;
- изменение пароля владельцем аккаунта;
- создание, редактирование и удаление собственных публикаций;
- отложенные публикации: записи с будущей датой видны автору сразу, а остальным пользователям — начиная с указанной даты;
- возможность снять публикацию с показа через административную панель;
- прикрепление изображений к публикациям;
- категории и местоположения, управляемые администратором;
- комментарии к публикациям с сортировкой от старых к новым;
- редактирование и удаление собственных комментариев;
- отображение количества комментариев в ленте, профиле и категории;
- пагинация ленты, страницы пользователя и страницы категории — не более 10 публикаций на страницу;
- отдельные страницы ошибок 403 CSRF, 404 и 500;
- статичные страницы «О проекте» и «Правила» на основе class-based views;
- файловый email-бэкенд для локальной проверки восстановления пароля.

## Технологии

- Python 3.12;
- Django 5.1.1;
- SQLite;
- Pillow для работы с изображениями;
- django-bootstrap5 для оформления форм и интерфейса;
- django-debug-toolbar для разработки.

## Структура проекта

```text
blogicum/
├── blog/              # публикации, комментарии, профили и формы
├── blogicum/          # настройки проекта и корневые URL
├── pages/             # статичные страницы и обработчики ошибок
├── templates/         # общие, блоговые, пользовательские и error-шаблоны
├── manage.py
└── db.sqlite3         # создаётся после миграций
```

Загружаемые изображения сохраняются в каталоге `media/`. Письма, отправленные приложением, сохраняются в каталоге `sent_emails/`; этот каталог исключён из репозитория.

## Установка и запуск

Клонируйте репозиторий и перейдите в его директорию:

```bash
git clone https://github.com/Torb7/django-blogicum
cd django-blogicum
```

Создайте и активируйте виртуальное окружение:

```bash
python3 -m venv venv
source venv/bin/activate
```

В Windows команда активации может выглядеть так:

```powershell
venv\Scripts\activate
```

Установите зависимости:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Из корневого каталога репозитория выполните:

```bash
cd blogicum
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

После запуска приложение доступно по адресу `http://127.0.0.1:8000/`, административная панель — по адресу `http://127.0.0.1:8000/admin/`.

Для разработки в настройках включён `DEBUG=True`. В этом режиме изображения из `media/` доступны через встроенную раздачу Django, а панель Debug Toolbar — по адресу `http://127.0.0.1:8000/__debug__/`.

## Основные адреса

| Адрес | Назначение |
| --- | --- |
| `/` | Лента опубликованных записей |
| `/about/` | Страница «О проекте» |
| `/rules/` | Страница с правилами сайта |
| `/profile/<username>/` | Профиль пользователя и его публикации |
| `/profile/edit_profile/` | Редактирование профиля владельцем аккаунта |
| `/category/<category_slug>/` | Публикации выбранной категории |
| `/posts/<post_id>/` | Просмотр отдельной публикации |
| `/posts/create/` | Создание публикации авторизованным пользователем |
| `/posts/<post_id>/edit/` | Редактирование публикации её автором |

| `/posts/<post_id>/edit_comment/<comment_id>/` | Редактирование комментария автором |

| `/auth/password_reset/` | Запрос на восстановление пароля |

## Работа с контентом

Авторизованный пользователь может создать публикацию, указав заголовок, текст, категорию, местоположение, дату публикации и необязательное изображение. После сохранения пользователь переходит в собственный профиль. Редактировать и удалять публикацию может только её автор; после удаления открывается страница подтверждения с содержимым публикации.

Новые категории и местоположения создаются администратором через `/admin/`. Там же можно управлять публикациями, комментариями и их статусом публикации.

Комментирование доступно только авторизованным пользователям. Автор комментария может изменить или удалить его, а на странице публикации комментарии выводятся в порядке добавления.

## Электронная почта

Проект использует файловый бэкенд Django:

```python
EMAIL_BACKEND = 'django.core.mail.backends.filebased.EmailBackend'
EMAIL_FILE_PATH = BASE_DIR / 'sent_emails'
```

Поэтому письма не отправляются на реальный почтовый сервер, а сохраняются отдельными файлами в `sent_emails/`. Это позволяет локально проверять сценарий восстановления пароля.
